# Economics and pilot plan

**The test:** data licensing + sponsorship + venue revenue ≥ uplinks + host incentives + hardware + operations.

## Pilot (one concentrated area)

1. Pick one building, campus, shopping street or community.
2. Install fixed gateways at venues whose internet plans permit public sharing (`ROLE=gateway` or `business`).
3. Launch the web app: discovery, onboarding, data choices, host controls.
4. Add Nøde routers as relays (`MESH=1`) to fill gaps; measure real coverage.
5. Test phone hosting only on validated devices and plans.
6. Sign paying data customers before expanding collection.
7. Then manufacture Nøde hardware (Home, Business, Relay, Gateway) on OpenWrt.
